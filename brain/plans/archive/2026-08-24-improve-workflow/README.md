## Findings considered and rejected

- **Build a custom checkout and payment processor in the first admin release**:
  rejected. `README.md` already points toward Shopify Storefront API, and
  MongoDB should not become an improvised payment authority. The plan defines a
  later Shopify-backed order operations module instead.
- **Add a generic drag-and-drop page builder**: rejected for the first release.
  Fixed, schema-validated content forms are safer, faster, and better matched to
  the small number of editorial sections in this storefront.
- **Adopt Mongoose immediately**: rejected. The official MongoDB driver plus
  Zod schemas is sufficient for the current repository size, avoids a second
  modeling layer, and can be revisited if domain complexity grows.
- **Rewrite the existing public storefront in TypeScript before starting**:
  rejected. New server, admin, validation, and test code should use TypeScript,
  while existing `.js`/`.jsx` files migrate only when touched by the data-source
  cutover.
